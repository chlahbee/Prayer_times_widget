
# ويدجت مواقيت  صلاة - APK

## كيفاش تبني APK

1. نزل Android Studio
2. File > Open > اختر مجلد prayer-widget-apk
3. Build > Build APKs
4. APK غادي تلقاه في app/build/outputs/apk/debug/app-debug.apk

## الاضافة للشاشة
1. ثبت APK
2. افتح التطبيق وحدد موقعك بـ GPS (كيعطيك الدقة بالمتر)، واستعمل زر الوضع الليلي/النهاري للتبديل بين الثيمين
3. اضغط مطولا على الشاشة الرئيسية > Widgets > مواقيت الصلاة
4. اسحبه - غادي يطلب تحديد الموقع

الافتراضي الدار البيضاء 33.5731,-7.5898
طريقة الحساب كتتختار حسب الدولة؛ الدول اللي ما عندهاش اختيار محدد كتستعمل الطريقة الدولية العامة (MWL). المنطقة الزمنية كتتحدد من إحداثيات الموقع عبر Aladhan.
